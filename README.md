## Overview
This repository contains the implementation and empirical time-complexity analysis of four sorting algorithms across input sizes $N \in \{5, 10, 50, 100\}$:
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort

## How to Run
```bash
python major_sorting_analysis.py
```
Make sure Python 3.x is installed. No external packages are required to run the benchmark script.
